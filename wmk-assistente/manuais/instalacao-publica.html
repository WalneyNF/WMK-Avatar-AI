Manual público de primeiro contato, hardware, desempenho, parâmetros e resolução de problemas. Atualizado em 07/11/2026.

1. O que é e o que está comprovado

O projeto combina SadTalker (animação facial por IA), uma interface web local, voz WAV gerada por recursos do Windows, integração opcional com Ollama e biblioteca de vídeos com exportação FFmpeg. A entrada é uma imagem de rosto e um WAV; a saída é um MP4.

Comprovado na máquina de desenvolvimento: um vídeo de 105 quadros (cerca de 4,2 s a 25 FPS) foi renderizado com sucesso, com etapa Face Renderer de 1h07min32s; a biblioteca e a exportação de outro MP4 foram testadas; nove testes automatizados da interface e API passaram. Não comprovado: instalação limpa em outro computador, execução CUDA nessa máquina, aceleração real por FPS neural ou desempenho em outros sistemas.

Este guia não promete instalação com um clique. O SadTalker original tem dependências antigas e pode exigir ajustes de versões. A instalação abaixo é um procedimento orientado para Windows; a lista completa de versões deve ser conferida no ambiente validado.

2. Compatibilidade e limitações de hardware

Qualidade: 256 px é a resolução neural configurada no backend atual. Exportar em 720p ou 1080p apenas amplia os quadros existentes; não recria detalhes faciais reais. Mais FPS de exportação não gera novos movimentos neurais.

3. Pré-requisitos Windows

  1. Windows 10 ou 11 de 64 bits; privilégios de instalação para Python, Git e ferramentas necessárias.
  2. Git instalado: git-scm.com.
  3. Python 3.8 de 64 bits para reproduzir o ambiente comprovado. Versões novas do Python podem quebrar dependências antigas. Fonte: python.org.
  4. FFmpeg, incluindo executável ffmpeg.exe: ffmpeg.org. Disponibilize-o no PATH; para a função atual de exportação da biblioteca, consulte a observação de caminho fixo abaixo.
  5. Internet inicialmente para baixar repositório, dependências e pesos do SadTalker. Para inferência local após instalar tudo, a internet pode não ser necessária.
  6. Opcional: Ollama para conversa com LLM. Não é necessário para animar uma foto a partir de WAV.

4. Baixar o projeto e preparar o Python

Exemplo no Windows CMD usando o disco D:. Troque D:\Ferramentas por uma pasta com espaço suficiente. Não é obrigatório usar o mesmo caminho do desenvolvedor.

cd /d D:\Ferramentas
git clone https://github.com/WalneyNF/WMK-Avatar-AI.git
cd WMK-Avatar-AI
py -3.8 --version
py -3.8 -m venv .venv
.venv\Scripts\python.exe --version
.venv\Scripts\python.exe -m pip --version

Se py -3.8 não existir, instale o Python 3.8 e reabra o terminal. O ambiente de desenvolvimento foi montado com uv e nem sempre possui pip no venv; uma instalação nova criada por venv normalmente inclui pip. Use apenas o gerenciador disponível no seu ambiente.

Dependências — atenção especial

O arquivo requirements.txt vem da base SadTalker e não foi validado como instalação completa e automática neste fork. É possível tentar:

.venv\Scripts\python.exe -m pip install -r requirements.txt

Se falhar, não misture pacotes aleatoriamente. Consulte o histórico técnico em README-PTBR.md e 03-INSTALACAO.md. Na máquina testada, versões importantes incluíram Python 3.8.20, torch 2.0.1+cpu, torchvision 0.15.2+cpu, torchaudio 2.0.2+cpu, librosa 0.9.2, scipy 1.10.1, face-alignment 1.3.5 e OpenCV 4.8.1.78. Isso é referência de compatibilidade, não um manifesto completo de dependências.

Para comparar a instalação com a máquina testada, gere um inventário de versões no computador que já funciona: uv pip freeze --python .venv\Scripts\python.exe (ou python -m pip freeze em venv com pip). Não publique dados pessoais ou arquivos de modelo junto com o inventário.

Clonar o GitHub não inclui automaticamente os checkpoints neurais. Consulte o release oficial SadTalker v0.0.2-rc e o repositório original para modelos e instruções. No ambiente testado existem, entre outros:

Outros arquivos auxiliares podem ser necessários para detecção facial e reconstrução 3D; confirme o que inference.py solicita. Alguns pesos podem ser obtidos automaticamente em execução, mas não dependa disso em instalações offline. Respeite licenças de pesos e arquivos.

6. Configurar FFmpeg e áudio

ffmpeg -version
where ffmpeg
powershell -NoProfile -Command "Get-Command powershell.exe"

Limitação conhecida de portabilidade: o servidor atual chama o FFmpeg da exportação avançada em D:\ffmpeg\bin\ffmpeg.exe. Em outros computadores, esse caminho provavelmente não existe. Para essa função, configure o caminho em wmk-assistente/server.py (duas chamadas qualidade_video.exportar(..., ffmpeg=...)) para o executável instalado. Isso não é necessário para abrir o Estúdio, mas pode impedir a exportação avançada.

A geração de voz usa wmk-assistente/voz.ps1 com o sintetizador de fala do Windows. As vozes disponíveis dependem do Windows e dos pacotes de idioma instalados. Se não houver voz compatível, use um WAV PCM de fonte externa em vez de depender da síntese do Windows. Não há integração universal de TTS garantida.

7. Diagnóstico antes da primeira execução

cd /d D:\Ferramentas\WMK-Avatar-AI
.venv\Scripts\python.exe --version
.venv\Scripts\python.exe -c "import torch; print('torch',torch.__version__); print('CUDA',torch.cuda.is_available())"
.venv\Scripts\python.exe inference.py --help
ffmpeg -version

CUDA False significa que a instalação atual não pode usar aceleração CUDA via PyTorch. A GPU aparecer no Gerenciador de Dispositivos não significa que ela está sendo utilizada. O backend atual passa --cpu explicitamente: instalar uma GPU nova sozinho não altera esse comportamento.

Se os comandos falharem, corrija o erro específico antes de iniciar uma renderização longa. Para reproduzir o ambiente testado, verifique versões, checkpoints e módulos ausentes.

8. Iniciar o servidor e usar as ferramentas

cd /d D:\Ferramentas\WMK-Avatar-AI
.venv\Scripts\python.exe wmk-assistente\server.py
Endereço localFunção
http://127.0.0.1:18765/Enviar foto, gerar WAV e usar chat opcional.
/estudioConfigurar animação antes de gerar, testar 2 s, salvar presets JSON.
/monitorAcompanhar logs, etapas, quadros e erros.

O endereço 127.0.0.1 é acessível apenas no próprio computador. Não exponha o servidor diretamente à internet: ele não possui autenticação de usuários ou isolamento adequado para serviço público. Mantenha o terminal aberto enquanto utiliza a aplicação.

11. Primeiro experimento seguro e comparação

  1. Escolha foto frontal e áudio curto; se necessário gere WAV de uma frase de 2–4 segundos.
  2. Estúdio: Teste rápido, duração 2 s, batch 2, threads automático, crop, pose 0, expressão 1.0, ângulos 0.
  3. Salve wmk-preset.json. Inicie apenas uma tarefa. Não feche o servidor durante a renderização.
  4. Quando concluir, anote tempo total, tempo do Face Renderer e qualidade da boca.
  5. Repita com somente um parâmetro alterado (por exemplo expressão 1.2, ou threads 2) e compare.
  6. Na Biblioteca, teste CRF 18 e CRF 23 sem repetir o modelo neural.

Não é possível avaliar qualidade facial apenas com a fotografia estática. A renderização de 2 s ainda pode demorar muitos minutos na CPU testada.

12. Erros comuns e soluções

ProblemaDiagnóstico / correção
Python não encontradoConfirme Python 3.8 e py -3.8 --version; use caminho completo do venv.
ModuleNotFoundErrorDependência ausente ou incompatível. Confira o nome e versões do histórico de instalação; não instale indiscriminadamente a versão mais nova.
CUDA FalseCPU-only, driver/GPU incompatível ou PyTorch sem CUDA. O backend força --cpu.
Checkpoints não encontradosBaixe modelos oficiais e verifique pastas e nomes. Git clone não baixa os pesos.
Erro de numpy.floatProblema conhecido de compatibilidade em versões antigas do SadTalker. O fork já contém correção localizada; confirme que o código está atualizado.
FFmpeg não encontradoInstale FFmpeg, confira PATH e o caminho fixo de exportação em server.py.
Falha na geração WAVVerifique PowerShell, execução de voz.ps1, disponibilidade da voz no Windows e saída de erro.
Porta 18765 ocupadaOutro processo pode estar executando o servidor. Evite iniciar uma segunda cópia.
Rosto não detectadoTeste imagem frontal realista, iluminada e sem acessórios obstruindo olhos e boca.
Vídeo demora muitoObserve logs. Em CPU antiga 105 quadros levaram 1h07min32s só na etapa Face Renderer. Não reinicie uma tarefa que continua avançando.
Histórico desaparece após reinícioJobs ficam em memória; MP4s continuam no disco. Use a Biblioteca para encontrá-los.

13. Segurança, privacidade, licenças e contribuição

O servidor local não foi preparado para exposição pública, autenticação multiusuário nem processamento de arquivos de terceiros em ambiente hostil. Não publique fotos pessoais, áudios, vídeos, caches, ambientes virtuais ou pesos sem autorização e sem verificar licenças. Para vídeos com rosto/voz de pessoas reais, obtenha consentimento e identifique conteúdo sintético quando apropriado.

O código e os modelos podem ter licenças distintas. Preserve atribuições do SadTalker, FFmpeg, bibliotecas e pesos; consulte Licenças. Para colaborar, abra issue ou pull request no repositório WMK Avatar AI, descrevendo sistema operacional, CPU/GPU, RAM, versão do Python, versão do PyTorch, comandos, logs sem dados sensíveis e passos de reprodução.

Roteiro de melhorias: instalador Windows reproduzível, manifesto de dependências, seleção portátil de FFmpeg, benchmark de hardware, fila persistente SQLite, GPU opcional validada e FPS neural configurável com sincronização de áudio.
